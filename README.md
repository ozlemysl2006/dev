##Hakkında

Phyton ve OpenCv kullanılarak siyah ve yeşil nesnelerin tespit edilmesi ve 3x3 grid üzerinde hagni hücrede olduğu belirlenmesidir.

##Kullanılan Teknolojiler
-Phyton 

-OpenCv

-Numpy

##Kurulum

```pip install opencv-phyton numpy```

##Çalıştırma 

```python mission.py```


##Öğrenilenler

-Webcam görüntüsü almak

-HSV ile renk tespiti yapmak 

-Kontur ve merkez koordinatları bulma

-Grid üzerinden satır ve sütun hesaplama

##Sorunlar ve Çözümleri

-Renk aralığının tespiti: HSV renk aralıkları deneme yanılma ile test edildi.

-Küçük şekiller: Küçük konturları elemek için alan kontrolü kullanıldı.
